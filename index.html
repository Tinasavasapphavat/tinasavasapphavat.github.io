Automated Binance ETL Pipeline

▹Config-driven column renaming & strict data typing
▹Date-partitioned Parquet via fastparquet

About Me

I'm Tin, a data engineer based in Thailand with 3+ years of experience building production-grade data infrastructure. I've worked across crypto (Bitazza), food-tech (Freshket), consulting (PwC), and insurance (FWD).

My day-to-day involves designing pipelines that are reliable, observable, and easy to extend — whether that's a Pub/Sub stream into BigQuery, a dbt medallion model in ClickHouse, or a zero-downtime CI/CD deploy via GitHub Actions.

I believe clean architecture pays off the moment you want to extend it. The ETL foundation I built for my personal crypto project required almost zero changes when scaling to a full medallion architecture in v3.
